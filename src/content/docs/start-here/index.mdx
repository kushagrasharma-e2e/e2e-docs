## What is E2E Cloud?

E2E Cloud is split into two products:

- **MyAccount** — cloud infrastructure. Compute nodes, networking, storage, backups, and API access.
- **TIR** — AI platform. Notebooks, datasets, training jobs, inference endpoints, and the GenAI API.

Both products share the same account identity and billing. You need an active, funded account before you can use resources in either product.

---

## Before you use anything

1. **Create an account** at the E2E Cloud portal.
2. **Add credits or a payment method** — resources are billed by usage. A node that exists is a node that costs.
3. **Choose a product** — if you need general compute, start with MyAccount. If you need AI workloads, start with TIR (TIR still requires a MyAccount-linked billing account).

→ [Account & Billing](/e2e-docs/account-billing/)

## How the docs are structured

Each product has four sections:

| Section | What it contains |
|---|---|
| **Documentation** | Concepts, resource lifecycle, states, limitations, billing behavior |
| **Guides** | Step-by-step tasks — create, configure, access, manage |
| **Developer** | API authentication, endpoint references, Terraform automation |
| **Troubleshooting** | Error-message-first help — cause, fix, support requirements |
