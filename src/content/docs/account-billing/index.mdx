# Account & Billing

## Create and manage account

Shared account documentation must cover account creation, identity, authentication, and support-safe profile workflows.

## Credits and recharge

Billing behavior must be backend-verified before final publication. Do not infer pricing or recharge rules from old docs.

## Invoices

Invoice docs must be verified from backend and frontend sources before publication.

## Usage reports

Usage report behavior must be verified before publication.

## MyAccount billing

MyAccount billing pages must remain separate from TIR billing details while linking to shared account concepts.

## TIR billing

TIR billing depends on shared account identity and billing, and must be verified from available TIR/MyAccount integration sources.

## Billing API references

Public API references must be generated from approved OpenAPI specs.

## Billing troubleshooting

Troubleshooting must be organized by public-safe error message.

## Support-assisted billing cases

Public docs may say when to raise a ticket and what user-safe information to include. Internal handling steps must stay private.
