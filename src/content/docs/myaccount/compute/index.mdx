# MyAccount Compute

## What this service does

Compute documentation will cover creating, accessing, securing, monitoring, and automating compute nodes after backend, frontend, and OpenAPI extraction is complete.

## Common tasks

- Create a compute node.
- Access a node.
- Configure networking and security.
- Add storage or backup when supported.
- Automate node workflows through approved API docs.
