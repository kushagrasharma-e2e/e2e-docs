# MyAccount Nodes

Nodes are MyAccount compute instances. A Node is created from an operating system or marketplace image and then managed from the MyAccount portal. Nodes connect to other MyAccount services for networking, security groups, SSH keys, block storage, backups, monitoring, saved images, snapshots, reserved IPs, floating IPs, and billing.

## What Nodes Do

Nodes provide virtual or dedicated compute capacity inside MyAccount. Depending on the selected plan, image, region, and account eligibility, Nodes can support:

- Node listing and detail inspection.
- Node creation from OS, saved image, marketplace image, or imported image where available.
- Multi-node creation with constraints on shared add-ons.
- Start, power off, stop, reboot, reinstall, lock, unlock, delete, and bulk actions.
- Convert-to-committed, plan upgrade or modification, and root storage upgrade where eligible.
- Console access for supported states.
- Saved image and snapshot workflows.
- CDP backup integration.
- Public IP, reserved IP, add-on IP, floating IP, IPv6, and VPC/private networking workflows where the related services support them.
- Security group attachment, SSH keys, password-based login configuration, disk encryption at creation time, and BitNinja integration.
- Monitoring graphs, monitoring alerts, action logs, and billing logs.

## Works With

- **Images:** Node creation depends on available OS, marketplace, saved, imported, and upgrade images.
- **Networking:** Nodes can use public IPs, reserved IPs, VPC/private IPs, IPv6, floating IPs, and security groups.
- **Storage:** Nodes have root storage and can attach block storage volumes. E1-series root storage can be increased through the root storage upgrade flow.
- **Backup:** CDP backup can be enabled during creation and managed after creation where supported.
- **Monitoring:** Node detail surfaces monitoring graphs, alerts, uptime, action logs, and billing logs.
- **Billing:** Node billing depends on plan, pricing model, commitment state, stopped or powered-off state, and attached resources.
